## Requirements

- Node.js 20.18.0 or newer
- npm
## Installation

```bash
# Clone or download this folder
cd /path/to/folder

# Install dependencies
npm install discord.js-selfbot-vg18-v13 chalk
```
##  Setup

### 1. Edit `config.json`
```json
{
  "token": "YOUR_DISCORD_TOKEN_HERE" // your discord account
}
```

### 2. Run the bot
```bash
node index.js
```
## 3 Commands
```
- !start - Make Sure You Use This Command In Dm Or Group_Dm 
- !stop - To Stop The Spam
```
